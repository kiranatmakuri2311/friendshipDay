HOW TO ADD YOUR OWN PHOTOS
===========================

Every page already looks for images in this exact folder, by these exact
file names. Drop a photo in with the matching name below (same name,
any of .jpg/.jpeg/.png works as long as you keep the .jpg extension used
in the code, or update the src in the HTML if you use a different one),
and it will appear on the site automatically. No code changes needed.
Until a file is added, the site shows a soft placeholder with that same
path printed on it, so you always know exactly what still needs a photo.
